## Quick Reference

### File Organization

| Directory | Purpose | Technologies |
|-----------|---------|---------------|
| `framework/` | Handler types & utilities | TypeScript |
| `bundler/` | Tree-shaking bundler | esbuild, TypeScript |
| `runtime/` | Function executor | Node.js, TypeScript |
| `firecracker/` | VM manager | REST API, Unix sockets |
| `controller/` | Orchestration & CLI | TypeScript, Node.js |
| `examples/` | Sample functions | TypeScript |

### Key Commands

```bash
# Setup
npm install
npm run build

# Deploy
npm run -w controller dev deploy <name> <file.ts>

# Invoke
npm run -w controller dev invoke <name> '<payload-json>'

# List functions
npm run -w controller dev list

# Bundling
npm run -w bundler dev bundle <entry.ts> -o <out.js>
```

## Data Flow

### Development (macOS)

```
TypeScript Function
  ↓
Framework (types)
  ↓
Bundler (esbuild, tree-shake)
  ↓
Minimal Bundle (.js)
  ↓
Controller (deploy)
  ↓
Runtime (Node.js process)
  ↓
Result
  ↓
Cleanup
```

### Production (Linux)

```
TypeScript Function
  ↓
Framework (types)
  ↓
Bundler (esbuild, tree-shake)
  ↓
Minimal Bundle (.js)
  ↓
Controller (deploy)
  ↓
Firecracker VM Manager
  ↓
Firecracker API Client
  ↓
Firecracker VMM (KVM)
  ↓
Lightweight Linux VM
  ↓
Runtime (Node.js inside VM)
  ↓
Result
  ↓
VM Cleanup
```

## Dependencies

### Direct Dependencies

```
framework/
  └─ (no external deps)

bundler/
  └─ esbuild           Tree-shaking bundler

runtime/
  └─ @firecracker-lambda/framework

firecracker/
  └─ node-fetch        HTTP client (for API calls)

controller/
  ├─ @firecracker-lambda/bundler
  ├─ @firecracker-lambda/framework
  └─ @firecracker-lambda/firecracker

examples/
  └─ @firecracker-lambda/framework
```

### System Dependencies

**macOS (Development):**
- Node.js 18+
- npm 8+

**Linux (Production - Optional):**
- Linux kernel with KVM support
- Firecracker binary
- Node.js 18+ (for runtime)

## Getting Started

1. Read: [GETTING_STARTED_MAC.md](GETTING_STARTED_MAC.md)
2. Run: `npm install && npm run build`
3. Deploy: `npm run -w controller dev deploy hello examples/hello.ts`
4. Invoke: `npm run -w controller dev invoke hello '{"name":"World"}'`

Done! 🎉
